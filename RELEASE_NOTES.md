# Seagreen v3.0.0 - macOS app + monitoring overhaul and redesigned web UI

- Native macOS app, refreshed Windows web UI, and a polished CLI.
- Resource monitoring, local recordings, workload comparisons, and exports.
- Quit / Force Quit, background-job controls, and the new Seagreen identity.

Mac: download the universal DMG or ZIP. Windows: extract the source ZIP and run **Launch Seagreen.cmd** with Python installed.
