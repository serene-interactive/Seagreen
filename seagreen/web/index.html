Know what a number means
Transparent by design.
Sources, scope, and limitations stay attached to your data.
Power source
No live power source
On Linux, supported and readable RAPL counters provide CPU-package energy. Windows and macOS web monitoring currently show resource data without inferring watts from CPU percentage.
The native Mac app also supports battery discharge readings on supported MacBooks and an optional Apple powermetrics file connection.
Unavailable means unavailable
What Seagreen measures
CPU
Counter differences over monotonic elapsed time. Process CPU is per logical core. The first sample and long gaps are excluded.
Memory & disk
Resident memory and disk-byte counters where the operating system permits access. Shared memory may appear in multiple processes.
Energy
Adjacent same-source samples integrated into Wh. Missing readings, source changes, counter resets, and long gaps are excluded. No guessed carbon score.
Privacy
Runs on 127.0.0.1 with a private per-launch access token. No external assets, telemetry, accounts, or cloud storage.
Monitoring
Sampling every 2 seconds. Live chart retains 5 minutes.
Recordings auto-save and stop after two hours. Saved sessions stay on disk until you delete them. Keep the terminal running while using the web UI.
